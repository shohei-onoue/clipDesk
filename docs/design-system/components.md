# 部品仕様 v2

共通の色・文字・操作領域はREADME、値はtokensを参照します。「現行」はコードで確認した構造、「実装時の規則」は今後の変更で満たす条件です。

## AppHeader

実装：`lib/widgets/app_header.dart`。Inkの背景と下端のAmberグラデーション、高さ61、タイトル24。左は戻るか画面固有操作、右は操作とメニューです。タイトルを中央に置き、長い場合は省略します。左右の操作数に応じて重なりを防ぎます。アイコンにtooltipを付けます。

## メインカード

実装：`menu_screen.dart`の`_MenuCard`。330×104、角丸15、Ink→Blue。左に既存イラスト、右にふりがなと題名。カード全体が遷移先の操作です。権限のある入口だけを表示し、通常の情報カードとは区別します。

## 情報カード・EmptyCard

White 8%の面、White 16%の枠。標準余白16、標準角丸はAppRadius.lg=12。現行の案件詳細・進捗などの角丸15は部品固有値です。要対応はAmberの枠を使い、語句も添えます。空の場合は何がないかを明記します。取得失敗を空表示に置き換えません。

## 依頼カードの3種類

| 用途 | 実装 | 構造 |
| --- | --- | --- |
| ホーム | home_widgets.dart / HomeRequestCard | 2列、暗い情報面、題名、状態タグ、担当・納期、進捗と数値 |
| 依頼一覧 | request_list_screen.dart / _RequestTile | 2列、上に動画の代替表示、下に白い詳細パネルと琥珀の進捗バー |
| ライブラリ等の行 | request_card.dart / RequestCard | 暗い情報面、左に進捗リング、右に題名・補足・状態タグ |

同名のカードへ無理に統合しません。一覧の現行基準は高さ270（動画160＋詳細110）、列間20・行間63.5です。これは基準幅での構成値で、長文や文字拡大を切り捨てるための固定制約ではありません。サムネイルがない場合は動画アイコンを使い、実画像があるようには扱いません。状態の語句は読み上げだけでなく画面にも表示することを改善条件とします。

## TopTabs・FilterChipsRow・SelectField

TopTabs：現行は進行中／完了。選択はWhiteの文字＋Blueの4px下線、未選択はWhite 70%です。

FilterChipsRow：語句・件数・選択チェックを表示。ホームは折り返し、進捗は横スクロール。現行の青文字・青枠は配色の記録であり、暗い面では青塗り＋White文字など読みやすい選択表現に改善します。選択状態をSemanticsにも渡します。

SelectField：常時表示のラベル、標準高さ48、White 55%の枠、先頭は「すべての〜」。ポップアップは背面が透けない面と読みやすい文字を使います。

## StatusTag・ProgressBar・ProgressRing・StepProgressCard

タグは必ず状態名を併記。Blue塗りはWhite文字、Amber塗りはInk文字です。進捗バーはAmber、未達部分は薄いWhiteまたは白パネル上のInkです。数値・段階名を併記し、色だけに頼りません。

主線は受付待ち→編集中→初稿確認→投稿済。要確認・修正は分岐です。4段階の進捗率は業務の達成量や残り時間を保証する数値ではありません。

## Button

| 種類 | 色 | 用途 |
| --- | --- | --- |
| 強調 | Amber / Ink | チャットの確認、確認画面の依頼・再送信 |
| 実行 | Blue / White | 編集開始、動画提出、承認、投稿完了など |
| 副操作 | White 8% / White、必要に応じ55%枠 | 修正する、戻る、補助操作 |
| 注意 | Amber / Ink＋具体的な動詞 | 要確認・修正依頼など、実行内容を明記 |
| 無効 | White 16% / White 70% | 操作できない理由を併記 |

同一領域で強調と実行を同じ強さで並べません。処理中は文言かインジケーターを表示し、多重操作を防ぎます。標準の実行ボタン高さ56、確認・送信66。最小操作領域44を守り、長いラベルは折り返せるようにします。

## ChatBubble・AssistantMessage・ChatInput・AppChip

現行のチャットはInk背景、ナビゲーターが左、ユーザーが右です。会話はヘッダー直下から上詰めで開始し、長くなった場合は最新の内容を表示します。返信はBlue＋White、案内はWhite 8%＋Whiteと16%の枠です。旧版の緑の返信・白い会話背景は使いません。

通常会話は本文15、吹き出し角丸18（尾側4）、アバター38。確認用AssistantMessageは本文18、角丸15、アバター44です。役割が異なる部品として記録します。

入力欄はInk、外側の入力バーはWhite 8%、角丸24。添付、選択肢、送信は読み上げ名を付けます。質問への回答方法を案内し、キーボード表示時も入力と送信を操作できるようにします。AppChipは選択肢の操作であり、進捗フィルターとは別部品です。

会話末尾に選択肢、完了時にAmberの確認CTAを置きます。未実装のAI生成・入力中演出・提案保存を必須部品にしません。

## AppBottomBar

Ink背景、高さ56。ホーム／新規依頼（編集者は進捗状況）／納品ライブラリの3入口。現行は中央がAmber、両端がWhite、アイコン領域48です。画面幅による縮小でも44以上を確保します。現在地の見た目・読み上げ状態と、常時表示の名称は改善対象です。

## AppDrawer

Ink→Blueのパネル、角丸15、細いWhite枠。現行幅350、パネル高さ490、行高56（390×844基準）。メイン／ホーム／新しい依頼（依頼者）／通知／納品ライブラリ、下部にログアウトです。白い全面ドロワーや未接続の設定・お問い合わせ入口は追加しません。低い画面ではスクロールさせ、ログアウトまで操作できるようにします。

## Field・標準部品・ダイアログ

入力はラベル・必要なヒント・エラーを持ちます。標準部品にはnightThemeを使います。エラーはAmberと明示的な語句、次の操作で伝えます。ダイアログは暗い面・White文字を基本に、閉じる操作と実行操作を明確にします。動画の読み込み・失敗・再生可能を区別します。
