## 画面ごとの判断

### メイン

カード群を画面中央に配置し、収まらない場合は縦にスクロールします。イラスト、ふりがな、Ink→Blueの面を基準にします。白い設定行の一覧へ置き換えません。スタッフの権限で入口を出し分けます。

### ホーム・依頼一覧・進捗

ホームは「期限が近い」「絞り込み」「案件」を順に見せます。完了タブでは期限帯を出しません。ホームの暗い情報カードと、依頼一覧の白い詳細パネルは意図的に使い分けます。進捗の4段階表示を一律に廃止したり、全画面をサムネイルグリッドへ置き換えたりしません。

カードには案件名と状態、必要な担当・納期を示します。長いタイトルの全文は詳細で確認できるようにします。状態は見える語句を優先し、進捗率だけに置き換えません。

### チャット・確認

会話はヘッダー直下の上端から開始し、ナビゲーターのメッセージを上詰めで並べます。長くなった場合は最新の質問・選択肢を表示します。指示書確認のまとめの配置は変更しません。質問は1つずつ進め、自由入力と選択肢を使います。添付の追加・削除と、読み込み中の案内を会話と区別します。完了時の確認、確認画面の送信にはAmberを使います。確認画面のナビゲーター付きまとめを基準とし、旧版の「必ず項目別カードに変える」という変更案は廃止します。

### 案件詳細

状態に応じた次の操作を上部にまとめ、指示書・添付・動画を下へ並べます。承認版と各版を語句で示します。承認と投稿済の区別、要確認・修正の分岐は業務仕様に従います。

### 通知・ライブラリ

通知は新着の枠・アイコンと語句を組み合わせます。既読は現行の暫定方式を維持し、デザインシステムで通知単位の既読へ変更しません。ライブラリは現行の行カードを基準にし、未実装の納品日・サムネイルを必須の実データとして扱いません。

### ログイン・登録

オープニング・ログインは専用の演出です。全画面に動画背景を展開しません。招待登録は暗い標準フォームとして扱います。

## 今後の改善事項（この刷新では画面未変更）

| 優先度 | 対象 | 実装時に満たす条件 |
| --- | --- | --- |
| 高 | 選択チップ | 暗い背景上の小さい青文字を読みやすくする。選択の語句・チェックも残す |
| 高 | 高さ・操作領域 | 横向き、低い画面、キーボード表示でも44px以上の操作領域を確保。固定高の文字切れを避ける |
| 高 | チャット離脱 | 入力済みの内容を失う前に案内。下書き保存は未確定の業務仕様として別途判断 |
| 中 | 下部ナビ | 現在地と入口の名称を視覚・読み上げで伝える |
| 中 | 動画提出 | ファイル読み込み開始から処理中を表示し、多重操作を防止 |
| 中 | ライブラリ | 読み込み、失敗、承認版なしを区別。失敗時は再試行を提供 |
| 中 | 依頼一覧 | 状態名を画面にも表示。読み上げ限定にしない |
| 中 | ドロワー | 低い画面や文字拡大時に項目・ログアウトまで到達可能にする |

## 変更時の確認

- 基準色4色と透明度、面ごとの文字色が合っている。
- メイン、ホーム、一覧それぞれのカードの役割を維持している。
- 読み込み・空・失敗・処理中・無効が区別されている。
- 狭い画面、横向き、文字拡大、キーボードで主要操作を実行できる。
- 色に加えて状態・操作の語句がある。
- 未確定の権限・保存・通知仕様をデザイン変更に含めていない。
